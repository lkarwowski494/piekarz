### 8.0 Zasady rozdziału

* **Poziomy pewności:**  
  * **math:** ścisły rachunek stechiometryczny i bilans masowy (szczebel 1). Wektory testowe obowiązkowe.  
  * **standard:** międzynarodowe normy piekarskie ICC, American Institute of Baking, definicje podręcznikowe (szczebel 2–3).  
  * **heurystyka:** ugruntowane reguły warsztatowe mistrzów rzemiosła (Calvel, Hamelman, Robertson) (szczebel 4).  
* **Zasada blokowania wydań:** Błąd w którejkolwiek z reguł matematycznych lub sanitarnych blokuje publikację aplikacji w App Store.
* **Krytyczna** (zasada roli 01, C-003): reguła, której błąd może zaszkodzić zdrowiu, życiu, mieniu albo położeniu prawnemu użytkownika; wymaga źródła ze szczebla 1–3 i przeglądu roli 06. „Blokuje wydanie” to osobna flaga jakości tej części, nie krytyczność.

### RD-02 True Baker's Percentage i bilans hydratacji całkowitej

* **Brzmienie:** Mąka zasypowa stanowi bazę 100%. Zakwas o hydratacji $H_z$ wprowadza do ciasta frakcję mąki $M_z$ oraz frakcję wody $W_z$. Rzeczywista całkowita hydratacja ciasta ($H_c$) uwzględnia obie frakcje.  
* **Wzór:** $M_z = \frac{W_{\text{zakwas}}}{1 + H_z}$; $W_z = W_{\text{zakwas}} - M_z$; $M_{\text{calkowita}} = M_{\text{zasypowa}} + M_z$; $W_{\text{calkowita}} = W_{\text{dolana}} + W_z$; $H_c = \frac{W_{\text{calkowita}}}{M_{\text{calkowita}}} \times 100%$ (dla zakwasu 100%: $M_z = W_z = 0,5 \times W_{\text{zakwas}}$).  
* **Jednostki:** masy w g; $H_z$ we wzorze jako ułamek (100% = 1,0), w tabeli w %; $H_c$ w %.  
* **Granica:** zakwas = 0 g (dolna granica dziedziny; masa ujemna to błąd danych); mąka zasypowa > 0 g.  
* **Podstawa:** S-01 (składniki jako procent masy mąki; procent całkowity przy prefermentach; szczebel 3) i rachunek (bilans masy).  
* **Krytyczna:** nie (błąd psuje ciasto, nie szkodzi zdrowiu).

### RD-07 Obliczanie ilości lodu do schłodzenia wody

* **Brzmienie:** Gdy wyliczona $T_{\text{wody}} < T_{\text{kran}}$, do uzyskania wymaganej temperatury konieczne jest zastąpienie części wody lodem, uwzględniając ciepło topnienia lodu ($80\text{ cal/g} \approx 334\text{ J/g}$): $$M_{\text{lodu}} = M_{\text{wody_calkowitej}} \times \frac{T_{\text{kran}} - T_{\text{docelowa}}}{80 + T_{\text{kran}}}$$  
* **Wzór:** $M_{\text{lodu}} = M_{w} \times \frac{T_{k} - T_{d}}{80 + T_{k}}$ dla $T_d < T_k$, inaczej $M_{\text{lodu}} = 0$; woda z kranu $= M_w - M_{\text{lodu}}$.

* **Granica:** $T_d = T_k$ (lód = 0 g).  
* **Podstawa:** rachunek (bilans cieplny: $m_l(80 + T_d) = (M_w - m_l)(T_k - T_d)$, lód o temperaturze 0 °C); ciepło topnienia bez przeczytanego źródła: [DO USTALENIA] (OP-13).  
* **Krytyczna:** nie.
